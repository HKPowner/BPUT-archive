# BPUT PYQ Archive 🎓

A simple, lightweight web archive for **Biju Patnaik University of Technology (BPUT)** Previous Year Questions (PYQs). 

This project is currently a work-in-progress and is being built as a helpful resource for students to find study materials in one place.

## 🚀 Live Site
Check out the site here: https://hkpowner.github.io/BPUT-archive/

## 📂 What's Inside?
- **Previous Year Papers:** Organized by semester and branch.
- **Easy Navigation:** Fast, simple HTML interface.
- **Open Resource:** Designed for students, by a student.

## 📝 How to Contribute
Since this is a fun project, if you have BPUT question papers (PDFs) and want to contribute:
1. Fork this repository.
2. Upload the PDF to the correct folder.
3. Link it in the corresponding HTML file.
4. Create a Pull Request!
